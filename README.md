# Portfolio Generator
### Project sections: 
- the nav bar: it contains three buttons: theme select, create new, export html. Also, it contains your name.

- build section: which contains the forms and inputs used for the right section.
- preview section: it contains all the inputs given in the left section and it changes each moment whenever you change anything.
<img width="1897" height="872" alt="image" src="https://github.com/user-attachments/assets/1e00602f-43f7-48d9-a2a1-81aa545bd8d0" />

### Project Features: 
- you can add your name, role, bio, skills, github account link.
- you can delete some skills, and everything changes instantly.
- after all of that, you can export your portfolio as an html file, which contain all your inserted info.
- local storage, whenever you enter the website or refresh it the whole text doesn't disappar.
- light and dark mode to make it look cool ngl I prefer the dark mode :)
